Tentang Website

Latar Belakang

Maraknya penyebaran informasi palsu atau hoaks di media sosial dan platform digital telah menjadi perhatian serius di Indonesia. Hoaks tidak hanya meresahkan masyarakat, tetapi juga berpotensi mengancam stabilitas sosial dan politik. Proyek ini dibangun sebagai upaya untuk menyediakan alat bantu berbasis teknologi Natural Language Processing (NLP) yang dapat membantu pengguna melakukan verifikasi awal terhadap kebenaran sebuah berita.

Teknologi yang Digunakan

Aplikasi ini ditenagai oleh model machine learning yang canggih untuk menganalisis teks berbahasa Indonesia. Berikut adalah teknologi (tech stack) utama yang digunakan:

  • Model LLM: IndoBERT yang telah di fine-tuning pada dataset berita hoaks berbahasa Indonesia.
  • Backend: Flask (Python) untuk melayani API model dan menangani logika pemrosesan.
  • Frontend: HTML, CSS, dan JavaScript murni untuk membangun antarmuka pengguna yang interaktif dan responsif.

Tujuan Proyek

Tujuan utama dari pengembangan aplikasi ini adalah untuk memenuhi syarat kelulusan program studi, sekaligus memberikan kontribusi nyata dalam upaya literasi digital dan perlawanan terhadap misinformasi di Indonesia.

DeteksiHoaks

Proyek skripsi untuk mendeteksi potensi hoaks berbahasa Indonesia menggunakan teknologi Natural Language Processing (NLP). Dengan metode fine tuning terhadap model IndoBERT Base P1
